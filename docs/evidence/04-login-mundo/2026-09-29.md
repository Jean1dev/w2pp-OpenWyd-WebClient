## Limitações do backend confirmadas em fonte

- `dbserver/internal/grpcsrv/server.go:AccountLogin` não impede login duplicado. `world.SetCargo` substitui o cargo compartilhado e `ReleaseCargo` o remove ao fechar uma sessão. Testar as conexões não comprova segurança de inventário/economia; não há mutação de itens no cenário de concorrência.
- `CreateCharacter` ainda usa atributos iniciais genéricos no dbserver. A seleção mostra dados desse backend, não uma garantia de paridade com os valores iniciais do cliente clássico.
- `accountSecure` aceita em caso de erro de persistência. O teste negativo exige uma rejeição real; não usa essa degradação como sucesso.
- `CitySpawn` pode ser ajustado até três células por `EmptyCellNear`. A validação permite esse ajuste, e logs do servidor registram a coordenada exata enviada.
- `CharacterSaveFor` persiste `MaxHP - EquipmentAttributeHP` e o equivalente para MP. A seleção usa essa representação persistida, enquanto o Field inclui equipamento. O primeiro teste de classe 0 reprovou incorretamente 105 != 100; a regra foi corrigida para comparar seleção com seleção e Field com Field após relogin. Isso não autoriza ignorar mudanças de atributos/equipamentos dentro de cada representação.

## Reprodução

```powershell
npm.cmd run world:checks
python tools/apply_openwyd_patches.py
$env:EMSDK = (Resolve-Path .cache/toolchains/emsdk).Path
python external/OpenWyd/webclient/client-wasm/tools/link_tmproject_wasm_startup.py --repo-root external/OpenWyd --dev --jobs 1 --link-opt-level O2
python tools/build_local_scene.py --page-only

# Suíte completa, sequencial; interrompe ao primeiro cenário reprovado.
npm.cmd run world -- --target reseau.proxy.rlwy.net:56950 --client-version 12000 --env-file .env

# Cenários independentes (cada linha inicia/encerra o próprio navegador e gateway).
node tools/verify_world.mjs --target reseau.proxy.rlwy.net:56950 --env-file .env --phases badpass,badpin
node tools/verify_world.mjs --target reseau.proxy.rlwy.net:56950 --env-file .env --phases classes --class 0
node tools/verify_world.mjs --target reseau.proxy.rlwy.net:56950 --env-file .env --phases login,enter,second,move,logout
node tools/verify_world.mjs --target reseau.proxy.rlwy.net:56950 --env-file .env --phases login,enter,second,mapchange
node tools/verify_world.mjs --target reseau.proxy.rlwy.net:56950 --env-file .env --phases login,enter,concurrent
```

Repetir `classes` com `--class 1`, `2`, `3`. Após mudar patches, reaplicar e religar o WASM antes de rodar. Credenciais vêm somente de `.env`/ambiente; capturas com assets permanecem em `.cache/world/<execução>/`. JSONs e logs só devem ser incorporados após sanitização e conferência. `capture_world_logs.py` lê janelas UTC delimitadas, remove identidades e nunca grava a saída bruta da CLI.
